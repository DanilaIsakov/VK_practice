# Презентация: RuVLM BenchMax

Краткая структура слайдов (можно перенести в PowerPoint / Google Slides / PDF).

---

## Слайд 1. Титул

**RuVLM BenchMax**  
Русскоязычная Vision-Language модель на открытых данных deepvk (VK)

Максимизация метрик на GQA-ru и MMBench-ru

---

## Слайд 2. Проблема

- Открытые VLM сильны на английском, но слабы на русском.
- Пример: `Intel/llava-gemma-2b` — **59.8** GQA (EN) vs **0.2** GQA-ru.
- Нужны модели, понимающие **изображение + русский вопрос**.

---

## Слайд 3. Цель

Дообучить компактную VLM и получить **максимальные метрики** на:

- **GQA-ru** → ExactMatch  
- **MMBench-ru** → ExactMatch / GPTEvalScore  

---

## Слайд 4. Задачи

1. Изучить архитектуру LLaVA / VLM  
2. Использовать открытые датасеты deepvk  
3. LoRA instruction tuning  
4. Оценка через lmms-eval  
5. Сравнение с baseline и оформление артефактов  

---

## Слайд 5. Данные VK (deepvk)

| Датасет | Зачем |
| --- | --- |
| LLaVA-Instruct-ru | диалоги и reasoning |
| GQA-ru train | short-answer VQA |
| GQA-ru test / MMBench-ru | честная оценка |

Коллекция: Hugging Face → deepvk / Vision-Language Modeling

---

## Слайд 6. Метод

```
Image → CLIP (freeze) → Projector → Gemma-2B (+ LoRA) → Ответ
```

- Стартовая точка: `deepvk/llava-gemma-2b-lora`
- Обучение: LoRA, bf16, 1 эпоха
- Оценка: `lmms-eval` (`gqa-ru`, `mmbench_ru_dev`)

## Слайд 8. Жизнеспособность

Где применима модель:

- поиск и модерация контента по описанию;
- помощник для людей с нарушением зрения (описание сцен);
- образовательные VQA-приложения на русском;
- прототип мультимодального ассистента в экосистеме VK.
